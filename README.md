# Laravel Interview Q&A App

A simple and elegant **Laravel web app** to store and review interview questions.  
It lets you add questions with tags (like Eloquent, Routing, Middleware, etc.),  
write formatted answers using **CKEditor**, and include code examples —  
all saved in a database and displayed beautifully with syntax highlighting.

---

## 🚀 Features

- Add interview questions through a form (no login required)
- Select tags like *Eloquent*, *Routing*, *Auth*, etc.
- Rich-text answers using **CKEditor**
- Code snippet section with syntax highlighting (using Prism.js)
- Store answers as HTML directly in the database
- Fully responsive UI (Bootstrap or Tailwind)
- Search and filter by category (optional enhancement)

---

## 🧱 Tech Stack

- **Framework:** Laravel 11  
- **Database:** MySQL  
- **Editor:** CKEditor 4  
- **Frontend:** Bootstrap 5 / Tailwind CSS  
- **Syntax Highlighting:** Prism.js
